# book-manage 后端接口文档 & 前端开发规划

> 服务地址：`http://localhost:8080`（WSL 中运行需用 WSL IP，如 `http://172.28.58.76:8080`）
> 统一响应格式：`{ "code": 200, "msg": "操作成功", "data": ... }`
> 状态码：200 成功 / 400 参数错误 / 401 未登录 / 403 无权限 / 404 不存在 / 500 系统错误 / 600 业务异常

---

## 一、后端接口总览

### 1. 认证接口 `/auth`（公开）

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /auth/login | 登录，body：`{username, password}`，返回 token + 用户信息 | 公开 |
| POST | /auth/register | 普通用户注册，body：`{username, password, realName}` | 公开 |
| POST | /auth/logout | 退出登录 | 已登录 |
| GET | /auth/info | 当前登录用户信息 | 已登录 |

### 2. 图书接口 `/book`

| 方法 | 路径 | 参数/body | 说明 | 权限 |
|------|------|-----------|------|------|
| GET | /book/page | pageNum、pageSize、bookName、author、category、bookStatus | 分页+条件查询（名称/作者/分类模糊，状态精确） | 已登录 |
| GET | /book/{id} | - | 按 ID 查询 | 已登录 |
| POST | /book/add | `{bookName必填, price必填, author, isbn, category, version, quality, bookStatus, remark}` | 上架图书（管理员，自动记录卖家为当前管理员） | 管理员 |
| PUT | /book/update | 同上（含 id） | 修改图书 | 管理员 |
| DELETE | /book/delete/{id} | - | 删除图书 | 管理员 |

### 3. 订单接口 `/order`（暂不涉及付款）

| 方法 | 路径 | 参数/body | 说明 | 权限 |
|------|------|-----------|------|------|
| GET | /order/page | pageNum、pageSize、status、buyerId | 分页+筛选（status：0待确认/1已成交/2已取消/3已拒绝）；普通用户仅能查自己的订单 | 已登录 |
| GET | /order/{id} | - | 按 ID 查询（普通用户仅能查自己的订单） | 已登录 |
| POST | /order/apply | `{bookId}` | 下单购买（buyerId 取当前登录用户，防越权；校验在售、非卖家本人、无待确认订单） | 已登录 |
| POST | /order/confirm/{id} | body 可选：`{remark}` | 确认成交 → 图书标记已售出 | 管理员 |
| POST | /order/reject/{id} | body 可选：`{remark}` | 拒绝订单 | 管理员 |
| POST | /order/cancel/{id} | - | 买家取消订单（本人或管理员） | 已登录 |
| DELETE | /order/delete/{id} | - | 删除订单 | 管理员 |

### 4. 用户接口 `/user`（管理员）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /user/page?pageNum=&pageSize= | 分页查询 |
| GET | /user/{id} | 按 ID 查询 |
| POST | /user/add | 新增用户（需传加密后密码，前端建议用注册接口代替） |
| PUT | /user/update | 修改用户（userType/status/realName 等） |
| DELETE | /user/delete/{id} | 删除用户 |

### 5. 日志接口 `/log`（已登录）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /log/page?pageNum=&pageSize= | 分页查询（写操作自动记录） |
| GET | /log/{id} | 按 ID 查询 |
| DELETE | /log/delete/{id} | 删除日志 |

### 6. 其他

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | / | 服务健康检查，返回"图书管理系统后端服务启动成功！" |
| GET | /test | 测试接口 |

### 接口调用示例（curl）

```bash
# 登录获取 token
curl -X POST http://127.0.0.1:8080/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
# → data.token 即后续请求头

# 带 token 请求（请求头 satoken: <token>）
curl -G "http://127.0.0.1:8080/book/page" \
  -H "satoken: <token>" \
  --data-urlencode "bookName=三体" --data-urlencode "pageNum=1" --data-urlencode "pageSize=10"

# 下单购买
curl -X POST "http://127.0.0.1:8080/order/apply" \
  -H "satoken: <token>" \
  -H "Content-Type: application/json" \
  -d '{"bookId": 1}'
```

## 二、前端开发规划

### 技术栈建议

| 项 | 选型 | 说明 |
|----|------|------|
| 框架 | Vue 3 + Vite | 组合式 API（setup 语法糖） |
| UI 组件库 | Element Plus | 表格/表单/弹窗/消息提示齐全 |
| 路由 | Vue Router 4 | 路由守卫控制登录态 |
| 状态管理 | Pinia | 存 token、用户信息 |
| HTTP | Axios | 拦截器统一加 token、处理 401 |
| 图表（可选） | ECharts | 图书分类统计大屏 |

### 页面结构规划

```
登录页 /login            ← 登录表单 → 存 token，跳转首页
注册页 /register         ← 普通用户自助注册
└─ 主布局（侧边菜单 + 顶栏）
   ├─ 首页 /dashboard    ← 数据概览（在售图书、已售图书、待确认订单、已成交订单、用户数、日志数）
   ├─ 图书管理 /book     ← 图书列表(条件搜索+分页)、上架/编辑弹窗、删除、下架
   ├─ 图书浏览 /library  ← 普通用户视角：只看在售图书，点"购买"
   ├─ 订单管理 /order    ← 管理员：全部订单、确认成交/拒绝/删除
   ├─ 我的订单 /my-order ← 普通用户：只看自己的订单（待确认可取消）
   ├─ 用户管理 /user     ← 管理员：用户列表、启用/禁用、角色修改
   └─ 日志管理 /log      ← 管理员：操作日志列表
```

### 路由与权限映射

| 路由 | 角色 | 说明 |
|------|------|------|
| /login、/register | 游客 | 已登录访问则重定向首页 |
| /dashboard | 所有登录用户 | 概览 |
| /book、/user、/log | 管理员 | 菜单按角色动态渲染 |
| /library、/my-order | 普通用户 | 普通用户主页面 |
| /order | 管理员 | 订单管理 |

### Axios 封装要点

```js
// request.js 核心逻辑
axios.interceptors.request.use(config => {
  config.headers['satoken'] = store.token  // 注入 token
  return config
})
axios.interceptors.response.use(
  res => {
    const { code, msg } = res.data
    if (code === 200) return res.data.data      // 直接返回 data
    if (code === 401) { store.clear(); router.push('/login') }  // 未登录跳登录页
    ElMessage.error(msg)
    return Promise.reject(msg)
  },
  err => Promise.reject(err)
)
```

### API 模块划分（src/api/）

```
api/
├── auth.js     # login/register/logout/info
├── book.js     # page/getById/add/update/delete
├── order.js    # page/getById/apply/confirm/reject/cancel/delete
├── user.js     # page/getById/add/update/delete
└── log.js      # page/getById/delete
```

### 关键交互逻辑（对接后端）

1. **登录**：POST /auth/login → 保存 token + 用户信息（含 userType）→ 按角色跳转（管理员→/dashboard，普通用户→/library）
2. **下单购买**：图书浏览列表行内按钮 → POST /order/apply（只需传 bookId，buyerId 由后端取当前登录用户）→ 成功提示"待管理员确认"
3. **订单处理**：订单管理表格 → 确认成交 POST /order/confirm/{id}（图书自动标记已售出）/ 拒绝 POST /order/reject/{id}，可填备注
4. **取消订单**：我的订单中"待确认"行 → POST /order/cancel/{id}（本人或管理员）
5. **菜单权限**：根据 userType 渲染（1=管理员全菜单，0=普通用户仅 图书浏览/我的订单）
6. **401 处理**：任何接口返回 401 → 清除本地 token → 跳登录页

1. `npm create vite` 初始化 + 安装 element-plus / axios / pinia / vue-router
2. 完成 request.js 封装 + 登录/注册页（先跑通 token 链路）
3. 图书管理页面（列表/搜索/上架/编辑/下架）
4. 订单流程页面（购买/确认/拒绝/取消）
6. 权限菜单 + 路由守卫收尾
