# 2026年8月7日 工作日志

## 项目：二手书买卖管理系统（由借阅系统改造）

> 本次将「二手图书借阅」整体改造为「二手书买卖」模型（暂不涉及付款通道，确认成交即完成交易）。

---

### 一、业务模型变更

| 项 | 借阅模型（旧） | 买卖模型（新） |
|----|--------------|--------------|
| 图书 | book_info 带 totalNum/availableNum 库存 | 一本书 = 一个在售条目，去掉库存 |
| 图书状态 | 0上架/1下架 | 0在售/1已售/2下架 |
| 图书字段 | - | 新增 price、seller_id、seller_name |
| 借阅记录 | borrow_record | trade_record 交易订单 |
| 订单状态 | 0待审/1借出/2已还/3拒绝 | 0待确认/1已成交/2已取消/3已拒绝 |
| 订单字段 | userId/bookId/expectReturnTime | buyerId/sellerId/bookName/orderPrice 快照 |

---

### 二、后端改造

#### 1. 数据库
- **重构** `sql/book_db.sql`：book_info 去库存加价格/卖家，borrow_record → trade_record，初始化含管理员/两个普通用户、7 本在售书、2 笔演示订单（密码统一 123456，BCrypt 加密）

#### 2. 新增订单模块
- 新建实体 `TradeRecord`、`TradeRecordMapper`、`TradeRecordService` + Impl、`TradeController`（`/order`）
- 接口：`/order/page、/{id}、/apply、/confirm/{id}、/reject/{id}、/cancel/{id}、/delete/{id}`
- `/order/apply`：仅传 bookId，buyerId 取 `StpUtil.getLoginIdAsLong()` 防越权；校验在售、非卖家本人、无待确认订单
- `/order/confirm/{id}`：@Transactional 联动将对应图书标记已售出

#### 3. 删除旧借阅模块
- 删除 BorrowRecord 实体/Mapper/Service + Impl/BorrowController，src 内无残留引用

#### 4. 图书模块调整
- `BookInfo` 去掉 totalNum/availableNum，增加 price(BigDecimal)/sellerId/sellerName
- `/book/add` 自动记录卖家为当前登录管理员

#### 5. 权限
- `SaTokenConfigure`：调整为 `/order/confirm/**、/order/reject/**、/order/delete/**` 需管理员
